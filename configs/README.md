# 配置与资源 / Configurations and Resources

`default.yaml` 保存原工作流的公开默认配置；仓库根目录的 `schemas/` 与 `prompts/` 保存可审计的 schema 和 prompt 资源。第一阶段实验包的有限 arm 配置在 `src/chiplet_layout_experiment/arms.py` 中定义。

`default.yaml` contains the public default configuration of the workflow. The repository-level `schemas/` and `prompts/` directories contain auditable schema and prompt resources. The finite Phase 1 arm catalog is defined in `src/chiplet_layout_experiment/arms.py`.
