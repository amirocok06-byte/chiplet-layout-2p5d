# 三类算法的五检查点轨迹

本轮实现回答：同一真实 Case、同一初始坐标和固定候选预算下，三类本地
算法怎样连续改变 priority、空间热代理和 HPWL 三张 map，以及参数怎样随迭代变化。

## 数据与实现

读取冻结的 2-Benchmarks/external/ATPlace2.5D/Case1..Case10。单位由 µm
换算为板轴归一化坐标，HPWL 输出毫米；百分比 pin offset 按“芯粒中心 +
百分比 × 芯粒尺寸”还原。所有算法共享同一 seed 和初始坐标；公开 .pl
文件是全零重叠占位，初始化改用确定性的板内散点，并报告初始重叠率。

算法由本项目的独立轨迹模块提供，不覆盖既有 smoke worker：

- SA：随机移动、Metropolis 接受和几何降温；保存温度、位移半径及接受结果。
- Analytical：平滑 HPWL、空间热代理和重叠惩罚的解析梯度与投影更新；
  保存学习率、平滑系数和梯度信息。
- RL：NumPy 线性 softmax 策略的在线 REINFORCE；保存动作、奖励、熵、
  baseline 和权重更新。使用实际学习更新，模型训练成本计入本次运行。

这些是可审计的算法族代表性实现。TAP、ATPlace 和 RLPlanner 的论文/源码
提供研究背景；本轮轨迹不能标成其官方实现的运行结果。

## 检查点与终止

每个 Case、每个算法配置 800 次候选迭代，保存 0/200/400/600/800 共五个
检查点。每个检查点导出一张三联图，故每个算法有五张三联图及一张
3 × 5 状态流总览。每一步的参数和指标都记录，而非只记录五个采样点。

检查点在同一个优化循环中采集；采集结束后，继续使用已有当前布局、随机数
状态、退火温度、动量或策略权重，直至预算耗尽。800 次预算完成是代码终止
条件，不代表数学收敛或全局最优。快照保存当前迭代布局，不能用最优历史布局
替换当前状态；重叠、无效最终布局须原样展示。

## map 与颜色

- Priority/order：真实网表的 incident-pin count 除以最大计数。同连接度
  保留相同值，不虚构 precedence；背景 sentinel 为 -1。分级顺序色与轮廓
  有助于识别芯粒，芯粒内部的常数不添加人工纹理。
- Thermal：Gaussian 功率密度空间扩散代理，尺度与芯粒尺寸和固定板内扩散
  比例 0.08 有关。该代理未经 HotSpot 校准，不使用温度单位。轨迹指标取
  芯粒中心处的代理最大值；绘图保存整个 256×256 场，另外记录场最大值。
- HPWL：每条真实 pin bounding box 中均匀分摊其毫米 HPWL，各像素总和保持
  为该布局的总 HPWL。非线性色阶展开弱贡献，色条保留原数值。

原始 map 为 256×256，显示采用 nearest，网格为 16×16。每个 Case 的三类
算法与五个检查点共享同一通道的色阶；禁止逐帧自动拉伸导致颜色含义变化。
差分图每个通道跨算法共享对称范围。颜色丰富度由真实场结构提供。

## 预算与证据

共同目标为 HPWL/初始HPWL + 0.3×thermal_proxy/初始proxy +
20×penetration_penalty。这里的 penetration 是轴向穿透惩罚，适合解析梯度；
它在大小不同的矩形发生包含时不等于真实相交面积。记录中的
overlap_fraction 单独按精确矩形交集面积计算，并据此判定合法性；
不能把优化惩罚直接标成几何重叠率。

本轮参数采用预先声明的 schedule；ATPlace JSON 作为输入归档记录哈希，
不声称复用加密 cgm/PPO 内核参数。轨迹展示参数变化的相关现象，不能单凭
这条轨迹证明参数的因果影响，后续需固定其余参数的配对扫描。

所有算法候选预算同为 800，但解析梯度、策略训练和目标评价的成本不相同。
逐次记录实际 evaluator/gradient 调用、优化耗时、快照采集耗时和隔离子进程
峰值内存；原始轨迹的横轴是迭代号。后续性能论文须增加同 wall-clock 和同
evaluator 预算的独立对照，不把本轮单 seed 演示当成公平速度排名。

输出包括五份坐标/指标 JSON、完整 gzip JSONL 参数轨迹、可再生原始 NPZ、
PNG/PDF、运行 summary 和总 manifest。SHA-256 固定输入与本项目源码，
QA 文件记录多面板对齐、字形尺寸与 PDF 碰撞审查。
