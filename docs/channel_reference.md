# 四个状态通道：计算、数值与读图说明

本说明对应 `connectivity-priority-thermal-hpwl-legality-v2`。数组顺序固定为
`[priority, thermal_proxy, hpwl, legality]`，单帧形状 `[4,256,256]`；横向快照从左到右按此排列，状态流从上到下按此排列。
三类算法 agent 是 SA、Analytical、RL；通道是它们共同看到的状态，并不是四个 agent。

## 一、统一坐标和网格

板宽高为 Bx、By（mm）。芯粒左下角为 x_i、y_i，宽高为 w_i、h_i。
投影计算使用分别除以板宽高的单位板坐标 u、v∈[0,1]，真实 HPWL 换回 mm。
像素列对应 x、行对应 y，原点在左下；坐标轴 0–256 表示原始像素。
叠加的 16×16 宏网格只是辅助阅读，每个宏格仍包含 16×16 原始像素。
图片采用 nearest 显示，不插值伪造细节；PNG 为 300 DPI，另导出 PDF/SVG。

## 二、M_priority：连接度优先级

**数据与公式。** d_i 是 netlist 中属于芯粒 i 的 pin 出现次数；同一芯粒在多条网中出现会多次计数。
它不是唯一邻居数，不计额外 net weight，也没有使用 timing criticality。
`q_i = d_i / max(max_j d_j,1)`。像素 g 与芯粒矩形存在正面积交集时视为覆盖：
`M_priority(g)=max(q_i : R_i覆盖g)`；无人覆盖时为 −1。
孤立芯粒 q=0；相同连接度保留相同 q，不人为分配不同 rank。
重叠时取 max，避免绘制结果依赖芯粒遍历顺序；第四通道负责显示被遮盖的重叠结构。

**图中表现。** 采用 16 级 viridis 色阶：低值偏深紫，中值偏蓝绿，高值偏黄。
色条固定 0–1，浅灰底表示 −1 空白；黑色矩形线是芯粒边界。
一块芯粒内部保持同色，随着布局移动，颜色块跟随其位置；在 netlist 不变时 q_i 不随优化迭代改变。
网页每个 Case 的“priority 数值如何得到”表给出芯粒名称、d_i 和 q_i，可逐项核对颜色。

**读图边界。** 高值只表示连接 pin 更多，是候选优化区域的启发式特征；
它不直接代表先放置、先执行、热点、长线网或时序关键路径。大片同色可能是输入本身连接度并列，不能为丰富颜色而改变数值。

## 三、M_thermal proxy：功耗扩散代理

**数据与公式。** A_i=w_i h_i（mm²），功耗 P_i（W）；c_i 是单位板坐标中的芯粒中心，
s_ia 是芯粒沿轴 a 的归一化尺寸，`sigma_ia²=s_ia²/12+0.08²`。
在每个像素中心 u_g 上计算：

`M_T(g)=sum_i [P_i/A_i × exp(−0.5 × sum_a ((u_ga−c_ia)²/sigma_ia²))]`。

因此大功耗、小面积芯粒的幅值通常更高，邻近芯粒的扩散场相加。
数学幅值由 W/mm² 构造，但该场没有热阻、层叠材料和真实散热边界条件，不能解释成温度或真实热流密度。
标量 `thermal_proxy_peak` 在芯粒中心采样取峰值；绘图在全部网格中心采样，两个峰值的采样位置不同。

**图中表现。** inferno 色图，低值黑紫，高值橙黄；`PowerNorm(gamma=0.6)`增强低中值差异。
色条写“Spatial thermal proxy”，刻度是原代理数值，不写 °C/K。
同一 Case 的全部算法、全部五帧共用范围；不会逐帧自动拉伸而掩盖变化。

**读图边界。** 亮处是当前代理场集中的区域。真实 HotSpot block 校准的跨 Case 留出 MAE 为58.91°C，
当前没有可靠的代理转温度映射；不能把该图下降写成“降温若干摄氏度”。

## 四、M_HPWL：引脚包围盒线长贡献

**数据与公式。** 引脚使用真实 offset：左下角 + 半芯粒尺寸 + percentage×芯粒尺寸。
对网络 n，`L_n=(max pin_x−min pin_x)+(max pin_y−min pin_y)`，使用 mm。
令 B_n 是该网引脚坐标的离散包围盒，K_n 是其像素数量：
`M_HPWL(g)=sum_n [w_n L_n/K_n × 1(g∈B_n)]`。
每条网均匀分配其贡献到包围盒；退化包围盒至少分配一个像素。
当前真实 Case 适配器只支持 two-pin nets，隐含 w_n=1；公式保留 w_n 以说明权重只能计一次。
像素求和约等于精确 HPWL，仅有浮点误差，不等同于完整布线长度。

**图中表现。** magma 色图；高贡献区域更亮，未被包围盒覆盖的区域为浅灰。
色条单位 mm/pixel。使用 SymLogNorm，线性区为共同最大值的1%，其余为对数压缩。
只在显示时屏蔽约机器精度级残差，原始数组不变。

**读图边界。** 亮处是长网/多个网络包围盒叠加的贡献区域；不是实际导线路径、路由拥塞或物理梯度。
不能仅凭局部亮度认定必须移动哪块芯粒，需结合布局、约束与动作收益。

## 五、M_overlap/legality：精确几何异常的空间投影

**重叠项。** 先计算每对芯粒的精确矩形交集，再计算它与像素 g 的面积交集：
`L_overlap(g)=sum_{i<j} area(g∩R_i∩R_j)/area(g)/max(N−1,1)`。
只共边或仅落在同一粗像素、但几何上没有正面积交集时，贡献为0。
三芯粒重叠保留三个 pair 的贡献；不是重叠并集的面积图。

**越界项。** 各芯粒的左/右/下/上越界距离分别除以对应板长，
乘以其切向区间覆盖该边像素的比例，投影到一像素宽的相应板边带，然后除以 N 后求和。
完全板外的芯粒仍投影到最近边界像素，避免异常在图中消失。
`M_legality = L_overlap + L_boundary`；值非负，不强制截断到[0,1]。

**图中表现。** 快照和状态流使用线性 Reds：0为白色，正值为浅红到深红；
板内红块定位重叠，板边红带定位越界；色条为无量纲违反强度。
相同 Case 的算法/时刻共用完整范围；红色值不是合法概率，也不能直接求和当作重叠率。

**精确裁判。** 图旁分别保留 `overlap_fraction`、`boundary_valid`、`valid`。
几何 evaluator 按精确矩形计算重叠并检查边界，使用记录的数值容差。
栅格为0不能代替 evaluator；容差附近图非零也不必意味着 valid=False。

## 六、变化图的颜色含义

四个通道都使用 `delta=M_after−M_before`。共用以0为中心的 coolwarm 色阶：
蓝色为减少、红色为增加、白色接近不变，每个通道的范围在算法间固定。
这与快照中“红色表示绝对违反强度”的含义不同，图题和色条均带 Δ。
priority 的蓝/红常表示芯粒颜色块移动，并不表示连接度本身变好/变坏；
热代理、HPWL 和几何违反的局部增加也不能单独概括整个布局质量，需要看全局精确指标及成本。

## 七、最小读图顺序

先读标题中的 Case/算法/step、overlap、valid、boundary，再按四通道定位连接结构、功耗代理集中区、线长贡献和几何冲突。
跨算法比较先确认同一输入状态和预算；独立五检查点轨迹只显示各自经过的状态。
模型训练直接使用原始 float32 张量及记录的训练归一化，不将网页颜色或 PNG 作为物理输入。
