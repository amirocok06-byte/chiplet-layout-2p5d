# 面向2.5D系统集成的芯粒布局方法：第一阶段 MVP-0/MVP-1

本阶段已经实现一个 CPU-only、离线、可审计的最小实验闭环：

```text
Bookshelf case
  -> chiplet_layout_experiment.canonical.Layout
  -> Geometry / pin-offset weighted HPWL / fixed thermal proxy
  -> SA / analytical / RL-compatible worker
  -> finite arm catalog
  -> JSONL samples + manifest
```

## 已实现边界

- `canonical.py`：统一的 board、chiplet、placement、pin、net 和 layout checksum。
- `evaluator.py`：确定性边界/重叠检查、带 pin offset 和 net weight 的 HPWL、固定功耗密度热反馈。
- `bookshelf.py`：只读适配现有严格 Bookshelf parser；不导入或执行资料目录中的代码。
- `workers.py`：SA smoke worker、透明 analytical worker、RL-compatible 本地规则基线。
- `arms.py`：六个有限 arm，配置哈希和固定预算；不进行连续超参数搜索。
- `sampling.py`：同一输入、seed 和 evaluator 下的全臂采样，以及带 `input_metrics`、输出 `metrics`、`delta_metrics` 和 evaluator 成本的 JSONL/manifest 输出。

`RLCompatibleWorker` 明确标记为 `local-rule-baseline`，不代表复现 RLPlanner；routed wirelength、HotSpot、CPLEX、PyTorch/CUDA 和正式 benchmark 结论不属于本阶段。

## 运行方式

实验模块可直接从源码导入：

```python
from chiplet_layout_experiment import (
    PhysicsEvaluator,
    default_arm_catalog,
    sample_arms,
)
from chiplet_layout_experiment.bookshelf import from_bookshelf
from chiplet_layout_experiment.workers import (
    AnalyticalWorker,
    RLCompatibleWorker,
    SAWorker,
)

layout = from_bookshelf(
    "path/to/case",
    board_width=100.0,
    board_height=100.0,
)
records = sample_arms(
    layout,
    default_arm_catalog(),
    workers={
        "sa": SAWorker(),
        "analytical": AnalyticalWorker(),
        "rl-compatible": RLCompatibleWorker(),
    },
    evaluator=PhysicsEvaluator(),
    seeds=(0, 1, 2),
)
```

结果必须记录输入 checksum、arm/config checksum、seed、统一 budget、evaluator 版本、合法性、HPWL、热反馈、前后指标差分、总 evaluator 调用数和失败原因。第一阶段只验证接口与公平预算，不把 smoke 结果表述为科学结论。

共享 `order` map 不得把 Bookshelf 的芯粒输入顺序直接当作物理优先级。调用 `rasterize_layout` 时必须显式传入 priority/precedence order，或在 `Layout.metadata["chiplet_order"]` 中提供已审核的顺序；没有该信息时应拒绝生成 order map。rank=0 是有效的最低优先级，因此 `M_order` 的空白区域固定编码为 `-1`，避免在图和 CNN 输入中把空白与最低优先级混淆。
