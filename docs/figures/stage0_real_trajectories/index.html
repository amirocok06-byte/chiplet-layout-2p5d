四通道布局状态 · 真实五检查点

从已有800次候选轨迹的0/200/400/600/800检查点重新投影，未重跑优化器。每帧四张256×256 map；同Case、跨算法和时间使用固定色阶。

通道数值含义可以判断什么
M_priorityq_i=d_i/max(d)，d_i为incident pin数；空白−1，断连芯粒0，并列保留；覆盖冲突取最大q连接度较高的芯粒在哪里；它不编码实际执行顺序，也不等于时序关键性
M_thermal proxy高斯功率密度扩散，无温度单位代理场集中位置；HotSpot留出MAE58.91°C，当前未获可信温度校准
M_HPWL真实引脚包围盒上的线长贡献，mm/pixel当前线长贡献集中位置；像素总和约等于HPWL
M_overlap/legality精确矩形交集按像素面积分配并归一化，加越界量的边界带投影；0表示未显示违反空间约束异常位置；细微重叠与全局合法性以精确evaluator为准

第四通道由精确几何交集生成，避免相邻芯粒落在同一像素内导致假重叠。它是观察通道，不等于候选动作合法掩码。三类Agent仍为SA、解析法、RL。

四通道计算公式与图例：怎样读颜色和数值

1. Connectivity priority：d_i为芯粒关联pin的出现次数，q_i=d_i/max(max(d),1)。像素覆盖多个芯粒时取最大q；无人覆盖为−1，断连芯粒为0。16级viridis：深紫低、蓝绿中、黄高，浅灰为空白，黑线为芯粒边界。连接数相同就应同色；颜色块随布局移动，但q值在netlist不变时固定。

2. Spatial thermal proxy：像素中心处计算Σ_i(P_i/A_i) exp[−½Σ_a(u_ga−c_ia)²/σ_ia²]，σ_ia²=s_ia²/12+0.08²；P以W、面积A以mm²给出幅值。inferno由黑紫到橙黄，PowerNorm γ=0.6；色条是原代理值，不是°C/K。标量峰值在芯粒中心采样，图在网格中心采样。

3. HPWL contribution：真实pin offset得到每网的mm制HPWL=L_n；将w_n L_n均匀分到其引脚包围盒的K_n个像素，M(g)=Σ_n w_n L_n/K_n。色条mm/pixel；magma亮处贡献较高，浅灰处无可显示贡献；SymLogNorm压缩动态范围。当前适配器为two-pin、w_n=1；此图不画实际走线。

4. Overlap / boundary violation：Σ_(i<j) area(g∩R_i∩R_j)/area(g)/max(N−1,1)，加上沿板边一像素带投影的归一化越界量。线性Reds：0白，正值浅红至深红；板内红块提示重叠，板边红带提示越界。它不等于合法概率或精确重叠率，必须同时读标题中的overlap、boundary和valid。

差分图：四列均为ΔM=M_after−M_before；coolwarm中蓝色减少、红色增加、白色接近不变。priority的变化主要是位置变化。快照第四通道的“红=绝对违反”与差分图的“红=增加”需区分。所有色标按同Case全部算法与五帧固定；300 DPI/16×16宏网格不改变256×256数据。
