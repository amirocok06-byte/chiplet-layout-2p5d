# 示例数据边界 / Sample Data Boundary

本目录预留给可公开分发的小型 Bookshelf 或 canonical-layout 示例。当前初始发布不自动复制个人数据、F 盘第三方 benchmark 或未经确认许可证的数据集。

This directory is reserved for small, redistributable Bookshelf or canonical-layout examples. The initial release does not copy personal data, third-party benchmarks from an external drive, or datasets without a confirmed redistribution boundary.
